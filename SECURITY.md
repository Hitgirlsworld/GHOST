# Security and privacy

GHOST captures potentially sensitive ChatGPT conversations when enabled. It is an experimental extension with no formal audit or separate at-rest encryption.

**Please do not publicly disclose security issues together with chat data.** Contact the maintainer privately using GitHub's private vulnerability reporting feature when it is configured; otherwise open a minimal issue with no exploitable details or sensitive data requesting a private channel.

Never commit conversation exports, credentials, logs with conversation bodies, screenshots with personal text, or browser-profile data.
